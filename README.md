# 🐉 PokéDex Explorer

[![Deploy to GitHub Pages](https://github.com/SujalBajracharya/PokeDex/actions/workflows/deploy.yml/badge.svg)](https://github.com/SujalBajracharya/PokeDex/actions/workflows/deploy.yml)

A high-performance, responsive PokéDex application built with **React** and **Vite**. This project leverages the [PokéAPI](https://pokeapi.co/) to provide comprehensive data about Pokémon, including stats, types, and high-quality imagery.

---

## 🚀 Live Demo
Experience the PokéDex in your browser:
**[View Live Demo](https://SujalBajracharya.github.io/PokeDex/)**

---

## ✨ Key Features
- **Comprehensive Database**: Browse through hundreds of Pokémon from the PokéAPI.
- **Dynamic Search**: Instantly find your favorite Pokémon by name or ID.
- **Detailed Stats**: Deep dive into Pokémon stats, abilities, and type advantages.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Modern UI**: Sleek, glassmorphic design system using Tailwind CSS.

## 🛠️ Tech Stack
- **Frontend**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **API**: [PokéAPI](https://pokeapi.co/)

## 📦 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Version 20 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/SujalBajracharya/PokeDex.git
   cd PokeDex
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
